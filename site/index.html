Faithful to the Frame:

How does a source's directional influence travel when LLMs turn an institutional document into a decision-facing evidence interface?

Code & data ↗ Read the findings ↓

The question

Faithfulness is necessary.
It is not neutrality.

Institutionally authored sources can be factually grounded while still organizing attention through selection, ordering, tone, comparison class, and emphasis. We ask whether that framing is preserved, attenuated, or synchronized as LLMs mediate evidence for downstream decision agents.

Main findings

What happens to a source frame?

  1. 01

    Source-faithful extraction preserves the source's directional skew.

    Raw disclosures elicit a strong positive-return skew. Canonical, no-synthesis extraction preserves it almost exactly: 80.1% versus 80.0% (p = 0.889).

  2. 02

    LLM synthesis attenuates the skew, but does not improve outcome alignment.

    Moving away from the source can change the downstream pattern. That disruption is not equivalent to debiasing or better decisions.

  3. 03

    Shared summaries synchronize evidence paths.

    Shared interfaces coordinate what receivers use and how they reason, while directional accuracy remains indistinguishable from chance across regimes.
